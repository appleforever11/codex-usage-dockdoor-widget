# Codex Usage 6.0.3

## What's new

- 🌙 **Luna-6** selects `gpt-6-luna`; ☀️ **Sol-6** selects `gpt-6-sol` for new chats.
- The chooser, dock, appearance controls, accessibility labels, and analytics use consistent names. GPT-5.6 Luna/Sol are no longer offered as writable defaults.
- Shared model metadata separates model identity from artwork labels. Existing session history still identifies its real generation, such as Luna-5.6 or Sol-5.6.
- Light, Medium, and Max reasoning remain available. Astra and Terra keep their existing model IDs.
- The 6.0.2 prepaid-credit formatting fix, saved page palettes, and personal hover/selection haptics are preserved.

## Download and update

- [Download the Mac installer](https://github.com/appleforever11/codex-usage-dockdoor-widget/releases/download/v6.0.3/Codex.Usage.for.DockDoor.Pro.v6.0.3.dmg).
- [Download the companion ZIP](https://github.com/appleforever11/codex-usage-dockdoor-widget/releases/download/v6.0.3/CodexUsage-v6.0.3.zip).
- Existing users can use **Check for Updates** in the companion app.

Supports Apple silicon and Intel Macs on macOS 14 or later. Requires DockDoor Pro and local Codex data. Select Luna-6 or Sol-6 once to update an existing new-chat default; opening the widget does not rewrite Codex configuration or existing chats.

## Marketplace compatibility

The marketplace follow-up starts from ejbills' merged [dashboard changes in #27](https://github.com/ejbills/dockdoorpro-widgets/pull/27). It keeps persistent card placement, move menus, shared session-file discovery, primary-color values, seven-day Activity/Models defaults, and the removal of drag/drop, detail sheets, and hover haptics.
