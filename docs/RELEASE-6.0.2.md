# Codex Usage 6.0.2

This private companion patch corrects how Codex prepaid credits are shown in the personal DockDoor Pro widget. It does not change the marketplace `codex-usage` variant.

## Download and install

- **[Download DMG — recommended](https://github.com/appleforever11/codex-usage-dockdoor-widget/releases/download/v6.0.2/Codex.Usage.for.DockDoor.Pro.v6.0.2.dmg)**
- **[Download ZIP](https://github.com/appleforever11/codex-usage-dockdoor-widget/releases/download/v6.0.2/CodexUsage-v6.0.2.zip)**

Requires **macOS 14 or later**, **DockDoor Pro**, and local Codex data. Supports Apple silicon and Intel Macs.

1. Open the DMG or extract the ZIP.
2. Open **Install Codex Usage.app**.
3. Click **Install Widget**; an existing personal widget is backed up and updated automatically.
4. Restart DockDoor Pro if it does not refresh the widget immediately.

Existing users can use **Check for Updates** in the companion app. The Sparkle feed is published with the release and the appcast signature is generated by the tag-driven workflow.

## What's fixed

- 🔧 Raw `credits.balance` values are no longer given a synthetic `$` prefix.
- 🧾 Long values such as `$1250.0000000000` now display as a readable unit-neutral balance such as **1,250 credits**.
- 🧭 The dashboard explains that prepaid credits and the weekly **General** allowance are separate account surfaces.
- 🔄 The live account path, session fallback, synced usage file, dock cards, and expanded quota card use the same formatter.
- 🧪 Added focused regression coverage for grouping, rounding, unlimited balances, and missing balances.

## Scope

This is a personal companion/widget patch. It preserves the 6.0 dashboard, haptics, page swiping, theme animation, transparent dock treatment, and Reflective Shelf beta support. The marketplace widget and its DockDoor-managed update path were not modified or published by this release.
