# Codex Usage 6.0.1 · Personal beta

This update refines the 6.0 dashboard with compact quota and metric layouts, clearer spacing, and consistent illustrated model buttons in both the dashboard and Appearance.

- Astra has a brighter star field and flare; Luna, Sol, and Terra each have distinct artwork.
- Appearance uses compact, readable labels and bounded theme previews. Reasoning buttons keep their labels clear.
- Optional hover feedback uses a rate-limited double pulse. Existing haptic preferences are respected.
- Cards can move between pages using their context menu. Layouts persist across launches, including empty pages.
- Cross-page native dragging is experimental: end-to-end dragging has not yet been confirmed on hardware. Use **Move to page** from the card context menu if a drag does not complete.

Validation: focused usage, dashboard layout, settings-preservation, and attribution checks; native preview inspection of the dashboard and Appearance. Hover feedback was confirmed on a physical trackpad. Release automation builds universal binaries, validates Developer ID signatures, notarizes the installer, and signs the Sparkle feed.

This is the personal companion edition. Marketplace delivery is reviewed separately upstream.
