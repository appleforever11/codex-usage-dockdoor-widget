# Codex Usage 6.0.1

Keep Codex usage limits, reset times, recent activity, and model information visible in DockDoor Pro. Version 6.0.1 polishes the four-page dashboard introduced in 6.0.0.

## Download and install

- **[Download DMG — recommended](https://github.com/appleforever11/codex-usage-dockdoor-widget/releases/download/v6.0.1/Codex.Usage.for.DockDoor.Pro.v6.0.1.dmg)**
- **[Download ZIP](https://github.com/appleforever11/codex-usage-dockdoor-widget/releases/download/v6.0.1/CodexUsage-v6.0.1.zip)** — the same installer app, compressed instead of a disk image.

Requires **macOS 14 or later**, **DockDoor Pro**, and local Codex data. Supports Apple silicon and Intel Macs.

1. Open the DMG or extract the ZIP.
2. Open **Install Codex Usage.app**. It installs itself into your user Applications folder.
3. Click **Install Widget** for a fresh installation; an existing widget is updated automatically.
4. Add the installed Codex Usage widget through DockDoor Pro if it is not already in your dock.

Existing users can use **Check for Updates** in the installer app. Both downloads are signed and notarized. The `appcast.xml` asset is required by the automatic updater; you do not need to download it. GitHub's automatic **Source code** archives are for developers, not installation.

## What's new

- Cleaner quota and metric layouts, with more readable spacing throughout the dashboard.
- Redesigned Astra, Luna, Sol, and Terra buttons shared by the dashboard and Appearance. Astra has a brighter star field and flare.
- Clearer Appearance labels, theme previews, and reasoning buttons.
- Optional double-pulse hover haptics on supported trackpads, respecting your existing preference.
- Move cards between pages using **Move to page** in a card's context menu. Your layout is saved across launches, including empty pages.

**Known limitation:** cross-page dragging is experimental and has not been confirmed end to end on hardware. Use the card's **Move to page** menu if dragging does not complete.

## Reflective Glass and marketplace availability

This download includes transparent dock content, themed rings, glow, sparkles, and model-first labels. **The reflective shelf itself is provided by DockDoor Pro**, not by this installer.

These downloads install the full companion edition, including model/reasoning defaults and Sparkle updates. The separate **[marketplace 6.0 update is awaiting review in PR #27](https://github.com/ejbills/dockdoorpro-widgets/pull/27)**. It is a read-only dashboard with DockDoor-managed updates; it does not include configuration editing or the full Reflective Glass treatment. This release does not publish that marketplace update.
