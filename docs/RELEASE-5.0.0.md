# Codex Usage private edition 5.0.0

Astra, Luna, Sol, Terra, and Rainbow themes now style the widget panel and progress ring. Astra alone adds animated white-violet stars along the filled arc, with a static Reduce Motion path. The model picker contains Luna, Sol, Terra, and Astra. Light uses the supported `low` reasoning value; legacy `instant` values read as Light.

The private companion keeps signed Sparkle updates and adds matching palettes. The marketplace edition remains read-only and uses DockDoor Pro updates exclusively.

## Distribution and installation

One universal Apple Silicon/Intel installer is provided with MacBook Neo and Mac mini filenames. Both named DMGs are byte-identical copies of the notarized universal DMG. The installer supports macOS 14 or later, preserves widget placement, and keeps backups.

Apple accepted app submission `147fbb0c-bed9-47d6-91bf-e09ddc4e35e6`. The app and DMG were stapled, validated, and accepted by Gatekeeper. See build/notarization-5.0.0.log for the DMG submission identifier and full local evidence.

The local install completed as `CodexProjectTracker-530d8018.bundle` version 5.0.0. Its binary matches the signed build, and DockDoor Pro has loaded that binary. `widgetStackStyle` and `widgetStackLibrary` remained unchanged. The previous widget was backed up under `WidgetInstallerBackups/20260904-185951-48817`.

The installed companion reports version 5.0.0 and passes Gatekeeper. Its manual Sparkle check opens successfully; the current public feed still reports 4.1.0, which is older than this local private build. No public 5.0.0 appcast or artifacts were uploaded during this task.
